# User Journey: Mobile Visitor to Premium Lead

## Journey Stages

### Stage 1: Awareness & Hook (The Hero Section)
**What user is doing:** Landing on the site (wajdan-hero) via a mobile browser.
**What user is thinking:** "Is this what I'm looking for? Does it look professional?"
**What user is feeling:** 😐 Neutral, skeptical.
**Pain points:** Slow loading video/animations on mobile data.
**Opportunity:** Fast-loading text, high-contrast dark theme (hero-section-dark), and a clear, thumb-friendly "See Pricing" primary button.

### Stage 2: Exploration & Trust Building
**What user is doing:** Scrolling down (using scroll-reveal), reading the problem-section, checking comparison-table, and reading 	estimonial-cards.
**What user is thinking:** "Okay, they understand my problem. But are they credible?"
**What user is feeling:** 🤔 Intriguied.
**Pain points:** Horizontal scrolling tables usually break on mobile.
**Opportunity:** Use stacked cards for the comparison table on small screens. Keep testimonials short (1-2 sentences) so they fit on one mobile viewport height. Use the guarantee-section to remove all friction.

### Stage 3: Decision & Action (Pricing & Contact)
**What user is doing:** Viewing pricing-cards and initiating the premium-contact form.
**What user is thinking:** "This fits my budget. Let's reach out."
**What user is feeling:** 😌 Decisive.
**Pain points:** Standard contact forms require too much typing on a mobile keyboard.
**Opportunity:** Use the premium-contact component with large tap targets, radio buttons for budget ranges instead of text inputs, and auto-complete for email/phone.

### Stage 4: Outcome
**What user is doing:** Submitting the form and seeing the 	oaster notification.
**What user is thinking:** "Done. When will they reply?"
**What user is feeling:** 😊 Relieved, accomplished.
**Success metrics:** Form submission takes under 45 seconds on a mobile device.
